# A better messaging platform for anyone, anywhere.
Kiki is a private, self-hosted, centralized, and decentralized messaging platform inspired by [Signal](https://signal.org). Kiki has all of the benefits of Signal with simple self-hosting and a small profile.
## Privacy
We can't see anything you do, and no one can back up anything you don't want backed up. Everything is encrypted all the way through, so everything you do can't be accessed by anyone you don't want to. 

## Communication
All of your messages and calls will transfer lightning fast, whether your device is connected to your server or not. Kiki has a special feature that makes us different from all the other messaging services. Kiki can switch between p2p or a server connection. This means that if your server shuts down or something unexpected happens, you can still message and call anyone through p2p. Seamlessly.

## Price
Everything is meant to run for free. Forever. No strings attached.
